# Bagian 1 - PHP Dasar

Folder ini berisi jawaban untuk soal PHP Dasar, terdiri dari:

- Soal 1
- Soal 2
- Soal 3
- Soal 4
- Soal 5

## Cara Menjalankan

Pastikan PHP sudah terpasang di komputer Anda.

Masuk ke folder `bagian_1`, lalu jalankan built-in server PHP:

```bash
php -S localhost:8000
```

Setelah server berjalan, buka browser dan akses:

```text
http://localhost:8000
```

Halaman `index.php` akan tampil sebagai menu untuk membuka masing-masing soal.

## Catatan

- Tidak memerlukan framework atau dependency tambahan
- Cukup menggunakan built-in server dari PHP
- File utama yang dapat diakses dari browser adalah `index.php`
